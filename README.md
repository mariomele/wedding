# Mario Mele, reportage wedding photography

Static portfolio site (HTML + CSS + JS, no build step), hosted on GitHub Pages.

- `index.html` page content: stories, delivery & pricing, selected frames, contact form
- `style.css` styles (light/dark follows the visitor's system setting)
- `main.js` lightbox, stories carousel, contact form (opens the visitor's email app, address in `CONTACT_EMAIL`)
- `img/` photos from the Pic-Time galleries, WebP; `-s` files are the 800px grid versions

Preview locally: `python3 -m http.server` in this folder, then open http://localhost:8000
